# Итоговый проект по курсу «Инженерия Искусственного Интеллекта»

В этой папке находится итоговый мини-проект по курсу.  
Проект демонстрирует применение методов и инструментов инженерии ИИ: работу с табличными данными, обучение модели машинного обучения, обертку в REST API сервис, версионирование данных с помощью DVC и контейнеризацию в Docker.

- **Название проекта:** `Сервис оценки стоимости подержанных автомобилей`

- **Группа:** `ИКБО-42-24`

- **Краткое описание**
> Проект решает задачу регрессии: предсказывание рыночной стоимости автомобиля на вторичном рынке по его характеристикам (год выпуска, марка, модель, пробег, тип кузова и др.).
> Для обучения используется модель регрессионного бустинга с CatBoost на открытых данных Vehicle Sales с Kaggle.

## 2. Структура проекта

Проект организован в следующей структуре:

- `requirements.txt` – зависимости проекта (библиотеки Python, необходимые для запуска).
- `report.md` – отчёт по проекту (постановка задачи, данные, эксперименты, результаты).
- `self-checklist.md` – чеклист самопроверки проекта перед сдачей.
- `notebooks/` – экспериментальные ноутбуки:
  - EDA, прототипы моделей, отдельные эксперименты.
- `src/` – основной код проекта:
  - модули для работы с данными;
  - обучение моделей;
  - запуск сервиса/скриптов.
- `data/` – демонстрационные/учебные данные:
  - **только открытые, синтетические или обезличенные данные;**
  - при необходимости – небольшие выборки для быстрого запуска.
- `configs/` – конфигурационные файлы:
  - `.yaml`, `.json`, `.env.example` и т.п.
- `tests/` – тесты (юнит-тесты, простые проверки).
- `artifacts/` – сохранённые модели, отчёты, результаты экспериментов.

Если структура проекта отличается от базовой, опишите это здесь.

## 3. Требования и установка

### 3.1. Требования

- Python `>= 3.10`.
- Установленный Docker (для запуска контейнера).
- DVC (Data Version Control) для работы с датасетом.

### 3.2. Установка окружения

```bash
# Перейти в папку проекта
cd project

# Создать виртуальное окружение (опционально, но рекомендуется)
python -m venv .venv

# Активировать окружение:
# Windows:
.venv\Scripts\activate
# Linux / macOS:
source .venv/bin/activate

# Установить зависимости
pip install --upgrade pip
pip install -r requirements.txt
```

- **4** – хороший, рабочий проект:

  - структура кода и конфигураций в целом адекватна;
  - по чеклисту выполнено **не менее 5** пунктов.
